# Concept-generation prompts

Both concepts were generated with the built-in Image Gen tool. Real UOTe
heatmap, waterfall, and strict-lower matrix images were supplied only as
scientific-content references.

## Library state

```text
Design the complete desktop main screen of a read-only scientific application
called "XRD Correlation Atlas". Use a compact app bar, a 248 px faceted-filter
rail, a flexible result media grid, a 340 px metadata inspector, and a bottom
compare tray. Preserve separate fields for correlation transform and display
profile domain, and for across-frame versus within-frame window semantics.
Use true white, cool-gray chrome, navy text, thin dividers, and scientific plots
as the visual focus. No marketing hero, gradients, glass, decorative metrics,
or bento-card layout.
```

## Compare state

```text
Extend the Library design into a full Compare workspace for three selected
plots. Show equal plot columns with zoom/fullscreen controls and a metadata
difference table. Explicitly distinguish "Correlation calculation: Log²" from
"Curve displayed: Original-positive". Highlight only differing metadata with a
subtle amber surface. Retain the restrained true-white scientific product
design and large readable plots.
```
